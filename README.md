# RSI Range Signals

Telegram-бот торговых сигналов по крипто-фьючерсам (@rsirange_bot). Продукт: **инструмент и
честная статистика**, не обещание доходности — авто-сканирование рынка, риск-менеджмент,
проверяемый журнал сделок, публичный канал с реальными результатами (не только сигнал, но и
его исход — TP или стоп).

Стратегия — Smart Money Concepts (SMC): свипы ликвидности, слом структуры (BOS/CHOCH), FVG/OB/BB,
модели входа «6226», Setup 1:1, LTF-POI, модели открытия. Бэктест на BTC/ETH/SOL за 12 мес
**не подтвердил устойчивого механического края** (см. `docs/chs_docs/` — вынесены из репозитория,
конспекты методологии и вердикт по бэктесту). Это осознанный выбор: бот работает в режиме
живого сигнального сервиса с честной статистикой, а не «гарантированной прибылью».

## Статус: работает вживую

Бот запущен, ведёт канал, принимает подписки, полностью управляется из Telegram
(без правки `.env` и рестартов). 94 теста, все зелёные.

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env        # заполни TELEGRAM_BOT_TOKEN и TELEGRAM_ADMIN_IDS
make init-db
make test                    # 94 теста, секреты не нужны (conftest подставляет dummy)
make run                     # запуск (или через launchd — см. ниже)
```

### Автозапуск (launchd, локальный Mac — без VPS)

```bash
cp deploy/com.rsirange.bot.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.rsirange.bot.plist
```

Бот переживёт перезагрузку Mac и рестартует сам при краше (`KeepAlive`). Логи — `logs/bot.log`.

**После правок кода** (launchd, не nohup):
```bash
launchctl kickstart -k "gui/$(id -u)/com.rsirange.bot"
```
Остановить совсем: `launchctl unload ~/Library/LaunchAgents/com.rsirange.bot.plist`

## Как это работает

1. **Poller** (`market_data.run_poller`) на закрытии каждой 15m-свечи сканирует watchlist
   (`SMCEngine.analyze`), находит сетапы.
2. **Режим `auto`** (по умолчанию): сигнал сразу пишется в журнал (`status=open`) и рассылается —
   в канал (полный пост) + подписчикам (по тиру: платные/админы получают всё, free — лимит/нед,
   дальше тизер с призывом подписаться).
   **Режим `semiauto`**: сигнал становится кандидатом, ждёт `/confirm`/`/reject` от админа
   (для форвард-эксперимента «есть ли edge у человеческого подтверждения контекста» — код есть,
   сейчас выключен, см. `docs/NEXT_STEPS_FABLE5.md`).
3. Каждый такт `journal.update_outcomes_from_bars` скорит исходы открытых сигналов по свежим барам
   (обязательное исполнение лимитного входа, «стоп первым» при неоднозначности) — TP/SL пишутся
   автоматически, без ручного вмешательства.
4. Закрытая сделка **публикуется в канал результатом** (✅/🛑 + R) — публичный трек-рекорд.
5. Обслуживание подписок (истечение, напоминания за 3 дня, авто-проверка USDT-оплаты) — тоже
   в такте poller'а.

## Управление из Telegram (без рестарта)

Все операционные настройки живут в таблице `settings` (`app/runtime.py`) поверх дефолтов из `.env`
и правятся админ-командами вживую:

| Команда | Действие |
|---|---|
| `/admin` | интерактивная панель (пауза, режим канала, пост статы) |
| `/status` | снимок всех текущих настроек |
| `/pause` · `/resume` | остановить/возобновить поиск сигналов |
| `/symbols` · `/addsymbol <s>` · `/delsymbol <s>` | watchlist |
| `/setmode auto\|semiauto` | режим сигналов |
| `/minconf <0..1>` | порог уверенности сетапа |
| `/minimpulse <N>` | мин. размер импульса в ATR (фильтр мелкой/шумной структуры) |
| `/channel on\|off` · `/channel <id>` · `/channelmode full\|teaser` | канал |
| `/post` | ручная сводка статистики в канал |
| `/price stars\|usdt\|days <N>` | цена подписки |
| `/freeweek <N>` | лимит бесплатных сигналов/нед |
| `/usdtlink <url>` | ссылка на ручной USDT-счёт (полу-ручной приём) |
| `/cryptobottoken <tok>` | API-токен Crypto Pay — включает авто-USDT без правки `.env` |
| `/usdtbonus <N>` | бонус-дней за оплату USDT вместо Stars (дефолт 2) |
| `/cornix on\|off` | Cornix-совместимый блок в постах канала (дефолт выкл) |
| `/grant <tg_id> [дней]` · `/revoke <tg_id>` | подписка вручную |
| `/users` | счётчики юзеров |
| `/announce <текст>` | объявление в канал + подписчикам |

Пользовательские команды: `/start` `/help` `/stats` `/calc <деп> <риск%> <вход> <стоп>` `/subscribe`
`/about` (честный дисклеймер) `/backtest` (честный итог бэктеста) `/glossary` (словарь SMC-терминов).

## Подписка и оплата

- **Telegram Stars** — работает "из коробки" (нативный Bot API, `currency=XTR`, провайдер не нужен).
- **USDT**: два пути.
  - *Авто* — токен Crypto Pay API (@CryptoBot → Crypto Pay → Create App) в `CRYPTOBOT_TOKEN`:
    авто-создание счёта + авто-активация после оплаты (`payments.poll_cryptobot`, проверка каждый такт).
  - *Полу-ручной* (сейчас включён) — ссылка на многоразовый счёт CryptoBot (`/usdtlink`), кнопка
    «Я оплатил» шлёт админу заявку с `tg_id`, дальше `/grant <id>` вручную.
- Оплата **идемпотентна** (не начислит дважды), продление добавляет дни к текущему сроку.
- Воронка free-тира, истечение подписки и напоминания — автоматические (`payments.py`).

## Безопасность и честность

- Дисклеймер в каждом сигнале («не финансовый совет», риск 1–2%).
- Публичный журнал неизменяем: исход пишет только `journal.py` по цене биржи
  (append-only `signal_events`), задним числом не редактируется.
- Идемпотентность платежей и сканирования (UNIQUE-констрейнты на уровне БД).
- **Executor (авто-исполнение сделок на ключах юзера) сознательно не реализован** — бэктест не
  показал доказанного края; торговать чужими деньгами по неподтверждённой стратегии нельзя.
  Гейт снят только если форвард (полуавтомат/`/report`) покажет положительный edge —
  см. `docs/NEXT_STEPS_FABLE5.md`, Фаза 2.
