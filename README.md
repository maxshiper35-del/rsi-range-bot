# RSI Range Signals

Telegram-бот торговых сигналов по крипто-фьючерсам (@rsirange_bot). Продукт: **инструмент и
честная статистика**, не обещание доходности — авто-сканирование рынка, риск-менеджмент,
проверяемый журнал сделок, публичный канал с реальными результатами (не только сигнал, но и
его исход — TP или стоп).

Стратегия — Smart Money Concepts (SMC): свипы ликвидности, слом структуры (BOS/CHOCH), FVG/OB/BB,
модели входа «6226», Setup 1:1, LTF-POI, модели открытия. Бэктест на BTC/ETH/SOL за 12 мес
**не подтвердил устойчивого механического края**. Осознанный выбор: бот продаёт не «точность»,
а неподдельность истории — публичный CSV-трек-рекорд с sha256-хэшем, весь по-настоящему
проверяемый (`/trackrecord`).

## Статус: работает вживую

Бот запущен, ведёт канал, принимает подписки (Stars + USDT), полностью управляется из Telegram —
кнопками или командами, без правки `.env` и рестартов. 199 тестов, все зелёные.

## Быстрый старт

```bash
pip install -r requirements.txt
make install-playwright     # headless Chromium для карточки недели (разово)
cp .env.example .env        # заполни TELEGRAM_BOT_TOKEN и TELEGRAM_ADMIN_IDS
make init-db
make test                    # 199 тестов, секреты не нужны (conftest подставляет dummy)
make install-hooks           # git pre-commit: lint+typecheck+test перед каждым коммитом
make run                     # запуск (или через launchd — см. ниже)
```

### Автозапуск (launchd, локальный Mac — без VPS)

```bash
cp deploy/com.rsirange.bot.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.rsirange.bot.plist
```

Бот переживёт перезагрузку Mac и рестартует сам при краше (`KeepAlive`). Логи — `logs/bot.log`.
Крах процесса и необработанные ошибки внутри отдельных команд — оба репортятся админу в Telegram
(top-level try/except + `dp.error()`), не только в лог.

**После правок кода** (launchd, не nohup):
```bash
launchctl kickstart -k "gui/$(id -u)/com.rsirange.bot"
```
Остановить совсем: `launchctl unload ~/Library/LaunchAgents/com.rsirange.bot.plist`

## Как это работает

1. **Poller** (`market_data.run_poller`) на закрытии каждой свечи младшего ТФ из
   `timeframes` (сейчас 1h; 4h — HTF-контекст) сканирует watchlist (`SMCEngine.analyze`).
   Скан 15m убран по 6-месячному бэктесту: минус на всех символах — см.
   `docs/UPGRADE_BRIEF_2026_07.md`.
2. **Режим `auto`** (по умолчанию): сигнал сразу пишется в журнал и рассылается — в канал
   (полный пост; при включённом флаге `signal_chart_enabled` — фото-карта сигнала: свечи +
   зоны входа/стопа/тейков, тумблер «🖼 График сигнала» в /admin) + подписчикам (по тиру: платные/админы получают всё, free — лимит/нед, дальше
   тизер). **Режим `semiauto`**: сигнал становится кандидатом, ждёт подтверждения оператора
   (форвард-эксперимент «человек vs механика», код есть — сейчас выключен).
3. Каждый такт `journal.update_outcomes_from_bars` скорит исходы по свежим барам (обязательное
   исполнение лимитного входа, «стоп первым» при неоднозначности) — автоматически, без ручной правки.
4. Канал видит весь жизненный цикл сделки HTML-постами (`templates.py`): сигнал → «вход
   исполнен» (свежий филл, колонка `filled_at`) либо «отменён» (лимитка не исполнилась) →
   результат (✅/🛑: R + движение цены + иллюстративный % при плече ×N — настройка
   `display_leverage` в админке, 0 = выкл). Раз в неделю — карточка недели (PNG) и полный
   CSV-журнал с sha256 в одном посте (`/trackrecord` — по запросу в любой момент).
5. Обслуживание: подписки, автобэкап (проверяется и алертится при пропуске), серия стопов подряд
   на активном сетапе — тоже в такте poller'а.

## Управление из Telegram

Постоянное меню внизу чата (`is_persistent` — не сворачивается; `/start` или `/help`).
Раскладка разная: у юзера — Статистика/Трек-рекорд/Калькулятор/Подписка/О боте/
Бэктест/Глоссарий/Промокод/Помощь; у админа — Статистика/Трек-рекорд/Админ-панель/
Статус/Health/Юзеры/Growth/По сетапам/Помощь (без подписческого контента — админ и
так получает все сигналы вне подписки). Telegram-меню «/» отключено (дублировало
клавиатуру) — полный список команд теперь только в /help. `/admin` — многоэкранная панель (стратегия/цены/
символы, тумблеры и диалоговый ввод чисел). Команды по-прежнему работают параллельно с кнопками
для всего — `/help` в самом боте даёт актуальный список. `/growth` (admin) — атрибуция по
источникам: приглашено/оплатили/%, честно считает только реальные платежи (не триал/промо).

## Подписка и оплата

- **Триал**: новый юзер при `/start` получает полный доступ на N дней (дефолт 5) один раз —
  не выдаётся повторно и не выдаётся тем, у кого когда-либо была подписка.
- **Промокоды**: `/promo <код>` (или кнопка) — +N дней, с опциональным лимитом применений
  и сроком годности; `/addpromo` создаёт код (admin).
- **Два тарифа Stars**: пробный (дефолт 10⭐/5 часов, выключается нулём в админке) и
  основной (1000⭐/30 дней) — оба редактируются из /admin без рестарта.
- **Разовая покупка сигнала** (paid media): кнопка «🔓 Открыть за N⭐» на тизере — PNG-карта
  + полный разбор за Stars; закрытые сигналы не продаются (исход и так в канале).
  Цена — в /admin → Цены, 0 = выкл (дефолт).
- **Money-back 7 дней**: /refund <tg_id> (admin) — возврат Stars через refundStarPayment,
  вычитаются только купленные дни (промо/триал-хвост не сгорает).
- **Telegram Stars** — работает "из коробки" (нативный Bot API, `currency=XTR`, провайдер не нужен).
- **USDT**: авто (токен Crypto Pay API в `CRYPTOBOT_TOKEN`) либо полу-ручной (ссылка на счёт +
  заявка админу).
- Оплата **идемпотентна** (не начислит дважды), продление добавляет дни к текущему сроку.
- Воронка free-тира, истечение подписки и напоминания — автоматические (`payments.py`).

## Бэкап и трек-рекорд

`data/signals.db` — единственный источник правды. `make backup-db` — разовый бэкап
(`data/backups/`, ротация 14); ежедневный авто-бэкап через `deploy/com.rsirange.backup.plist`
(04:00, независим от процесса бота, SQLite Backup API — онлайн-копирование). Пропуск бэкапа >26ч
алертит админу. Каждая публикация трек-рекорда пишет sha256 в `ledger_hashes` — история проверяема
даже если канал позже удалят.

## Безопасность и честность

- Дисклеймер в каждом сигнале («не финансовый совет», риск 1–2%).
- Публичный журнал неизменяем: исход пишет только `journal.py` по цене биржи
  (append-only `signal_events`), задним числом не редактируется.
- Идемпотентность платежей и сканирования (UNIQUE-констрейнты на уровне БД).
- **Executor (авто-исполнение сделок на ключах юзера) сознательно не реализован** — бэктест не
  показал доказанного края; торговать чужими деньгами по неподтверждённой стратегии нельзя.
