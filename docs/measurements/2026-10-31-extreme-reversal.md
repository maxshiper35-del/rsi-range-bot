# Замер: разворот после экстремальной часовой свечи (регистрация 2026-10-30, ДО прогона)

Исследуется самостоятельная стратегия, а не фильтр к нынешней: вход против экстремальной 1h-свечи.
Экстремальная — больше k×ATR, то есть каскад ликвидаций или длинный фитиль. Фильтр «снимать входы
при шоке BTC» — другой вопрос, он отвергнут 29.10 (`2026-10-29-btc-shock-filter.md`).

Исполнение моделируется на минутных свечах — по уроку замера реализма трейла
(`2026-10-30-trail-realism.md`): часовая модель завышает результат.

## Вопрос

Даёт ли вход против экстремальной часовой свечи положительное матожидание после издержек при
исполнении по 1m?

## Данные

- **Вселенная.** Кандидаты — USDT-перпетуалы Bybit из `cache_univ/instruments.json`: 1121 id,
  включая 310 закрытых. Каждый день берём топ-30 по обороту за 30 предыдущих дней (дневные свечи,
  поле turnover). Символ допускается, если у него не меньше 60 дней истории. Членство дня d считается
  только по данным до d, без заглядывания вперёд.
- **Свечи.** 1h (Bybit kline, interval 60) — по символам, хоть раз попавшим в топ-30. 1m — окна
  сделок; общий кэш `data/cache_tf/m1`, качаю через `scripts/fetch_m1.py` в 1 поток.
- **Фандинг** — история Bybit `/v5/market/funding/history`.
- **Периоды:**
  - учёба — 2022-01-01…2023-12-31;
  - проверка — 2024-01-01…2026-07-31, пять отрезков: 24H1, 24H2, 25H1, 25H2, 26-01…07;
  - заморозка — с 2026-08-01 до конца данных. Одна финальная оценка выбранного варианта.
- Свечи события относятся к периоду по времени закрытия.

## Правила

- **Событие** — закрытая 1h-свеча t.
  - ATR = SMA(TR, 14) по свечам t−14…t−1.
  - Мера — range = high − low либо body = |close − open|. Событие, если мера > k×ATR.
- **Объём** (вариант): volume_t ≥ 3 × median(volume t−24…t−1).
- **Направление** — против доминирующего хода: LONG, если (open − low) ≥ (high − open), иначе SHORT.
- **Стоп** — за экстремумом: LONG — low − 0.1×ATR; SHORT — high + 0.1×ATR.
- **Вход:**
  - *market* — open 1m-бара, начинающегося через минуту после закрытия события. Тейкер плюс
    проскальзывание.
  - *limit* — цена close − 0.2×range для LONG (close + 0.2×range для SHORT), выставлена через минуту
    после закрытия события, живёт 3 ч. Исполнение — только если цена прошла уровень хотя бы на 1 тик
    (мейкер). Если лимит оказался за стопом или ближе 0.25×ATR к нему — сделки нет.
- **Риск** R = |вход − стоп|. Если R < 0.5×ATR — сделки нет.
- **Выход:**
  - *target f* — лимит на вход ± f×range, f ∈ {0.5, 1, 1.5}. Мейкер, нужен проход хотя бы на 1 тик.
    Потолок удержания 24 ч от входа, дальше выход по рынку.
  - *time T* — выход по рынку через T ∈ {4, 12, 24} ч от входа, без цели.
  - *стоп* — стоп-маркет: цена стопа (либо open минуты, если гэп хуже) минус проскальзывание, тейкер.
- **Внутри минуты** порядок худший: стоп раньше цели. В минуту исполнения лимитного входа цель не
  засчитывается.
- **Одна позиция на символ.** Событие при открытой позиции по тому же символу пропускается.
- **Издержки:**
  - тейкер 0.055%, мейкер 0.02%;
  - проскальзывание 0.02% на каждом тейкер-исполнении;
  - фандинг — по факту, на каждый расчётный момент внутри удержания.

## Сетка — 144 варианта

| Параметр | Значения |
|---|---|
| k | 2.5, 3, 4 |
| мера | range, body |
| объём | нет, да |
| вход | market, limit |
| выход | target 0.5, 1, 1.5; time 4, 12, 24 |

## Правило выбора — только учёба

Рассматриваются варианты, у которых на учёбе не меньше 200 сделок. Из них выбирается вариант с
максимальным средним net R на сделку; при равенстве — с большей ΣR. Топ-5 учёбы публикую.

## Критерий «кандидат» для выбранного варианта

1. На проверке средний net R на сделку > 0, и ΣR > 0 в каждом из пяти отрезков.
2. Соседи тоже в плюсе: средний net R на сделку > 0 и на учёбе, и на проверке. Соседи — варианты,
   отличающиеся на один шаг k, либо на один шаг f или T внутри своей семьи выхода.
3. На проверке не меньше 150 сделок.
4. На проверке ΣR > 0 и без 5 лучших сделок, и без 2 лучших календарных дней.

Если хоть одно не выполнено — «не кандидат».

Заморозка оценивается один раз, после того как вердикт по проверке записан. В отчёте она идёт
как есть.

## Поправка на перебор

Из 144 вариантов лучший на учёбе ожидаемо завышен. Поэтому решают только проверка, соседи и
устойчивость.

## Что отчитываю дополнительно (на вердикт не влияет)

- long и short отдельно;
- максимум одновременных позиций и вариант с потолком в 5 одновременных позиций;
- ложится ли стратегия в формат сигнала бота: вход, стоп, цель.

## Поправка 1 — до любого прогона результатов (2026-10-30)

Событий оказалось 39 002: все 1h-свечи вселенной с range ≥ 2.5×ATR за 2021-10…2026-10.

| период | событий |
|---|---|
| учёба | 17 290 |
| проверка | 18 150 |
| заморозка | 2 466 |

Минутные окна на все события — около 47 тыс. запросов, то есть примерно 4.7 ч при ≤2.8 запроса/с
с IP прод-бота. Поэтому, до подсчёта какого-либо P&L:

- **Сетка (все 144 варианта, все периоды) исполняется на 5m-свечах Bybit.**
  - Внутри 5m-бара порядок худший: стоп раньше цели. В бар исполнения лимитного входа цель не
    засчитывается. Это консервативно относительно 1m.
  - Market-вход — open первого 5m-бара после закрытия события (минута :00, а не :01), плюс
    проскальзывание.
  - Выход по времени — open первого 5m-бара не раньше вход + T.
  - Остальные правила без изменений.
- **Подтверждение на 1m обязательно.** Если выбранный вариант проходит критерии 1–4 на 5m, его
  перепроверяю на настоящих 1m-свечах за проверку и заморозку (окна только сделок этого варианта).
  На 1m должны выполняться критерии 1, 3 и 4. Только тогда — «кандидат». Не прошёл на 5m — «не
  кандидат», 1m-этап не нужен.

## Поправка 2 — до любого прогона результатов (2026-10-30), заменяет 5m из поправки 1

5m-окна стоят столько же запросов, сколько окон: по одному запросу на окно, всего 25–39 тыс.
запросов, это 2.5–4 ч. Разрешение тут не помогает. P&L ещё не считался. Поэтому:

- **Сетка исполняется на 1h-свечах**, по правилам ниже.
  - *Market-вход* — open часа сразу после события, плюс проскальзывание.
  - *Лимитный вход* — первый час из трёх, где цена прошла уровень хотя бы на 1 тик; цена исполнения
    — уровень лимита. В этом часе стоп засчитывается: путь к стопу проходит через лимит. Цель в этом
    часе не засчитывается.
  - *Стоп в часе* (без цели в том же часе) — исполнение по стопу либо по open часа, если гэп хуже.
    Тейкер плюс проскальзывание.
  - *Цель в часе* (без стопа) — исполнение по цели, мейкер.
  - **Если в одном часе тронуты и стоп, и цель, час разбирается по 1m-свечам** (общий кэш,
    `fetch_m1`). Внутри минуты — худший порядок. Нет 1m — стоп.
  - *Выход по времени и потолок 24 ч.* При market-входе — open часа вход + T. При лимитном — open
    часа (час исполнения + T + 1), то есть удержание не меньше T.
- **Подтверждение на настоящих 1m** — как в поправке 1, только если выбранный вариант прошёл
  критерии 1–4.

## Известные ограничения

- Вселенная взята из текущего списка инструментов Bybit, включая закрытые. Совсем старых
  делистингов там может не быть — для лонгов после обвалов это оптимистичный перекос.
- Свечи, фандинг и исполнение — по Bybit, а executor торгует на BingX.
