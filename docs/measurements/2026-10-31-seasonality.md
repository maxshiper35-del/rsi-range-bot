стратегия после издержек в минусе на всех участках. Идёт поиск края в других семействах

## Шаг 1. Карта сезонности (описание, не стратегия)
- **Час:** r = close/open − 1 у 1h-бара, открывшегося в час h UTC. На объект — 24 ячейки.
- **День недели:** r = close бара 23:00 / open бара 00:00 − 1 для каждого полного UTC-дня
  (24 бара). На объект — 7 ячеек.
- В каждой ячейке — среднее, стандартное отклонение, n и t = среднее / (sd/√n), отдельно на
  учёбе и на проверке.
- **Повторяемость рисунка:**
  - корреляция Пирсона между профилем учёбы и профилем проверки (24 средних по часам, 7 по дням);
  - совпадение знаков;
  - доля ячеек с |t_учёба| > 2, у которых на проверке тот же знак.

### Поправка на шум (множественные проверки)
1. **Бонферрони:** для часов |t| > 3.08 (α = 0.05/24, двусторонний), для дней |t| > 2.69
   (0.05/7).
2. **Перестановочный тест, 1000 повторов:**
   - часы — внутри каждого UTC-дня 24 бара случайно переставляются между метками часа. Сохраняется
     дневная волатильность, разрушается привязка к часу;
   - дни — внутри каждой недели (пн–вс) 7 дней переставляются между метками.

   Для каждого объекта и участка: ожидаемое под шумом число ячеек с |t| > 2, 95-й перцентиль
   max|t| и p-значения для наблюдённых max|t| и числа ячеек с |t| > 2.

## Шаг 2. Стратегии «держать в окне» — 9 вариантов, выбор только на учёбе
Профиль выбора — средняя валовая доходность окна на учёбе, усреднённая по BTC и ETH (BTC+ETH).
- **S1 — лучшее окно, лонг.** Непрерывное окно длиной L ∈ {1, 2, 3, 4} ч, начало h ∈ 0…23 (через
  полночь можно): 96 окон, берётся максимум средней доходности окна на учёбе.
- **S2 — лучшее окно, шорт.** Те же 96 окон, берётся минимум.
- **S3–S6 — сессии.** Окна фиксированы заранее, направление — по знаку средней на учёбе:
  - S3 — Азия, 00:00–08:00;
  - S4 — Европа, 08:00–13:00;
  - S5 — США, 13:00–21:00 (накрывает открытие NYSE 13:30/14:30 UTC; переход на летнее время не
    моделируется);
  - S6 — после США, 21:00–24:00.
- **S7 — выходные:** пятница 21:00 UTC → воскресенье 22:00 UTC (пауза CME, приблизительно, без
  летнего времени). Направление — по знаку на учёбе.
- **S8 — лучший день:** лонг на сутки 00:00–24:00 UTC в день недели с максимальной средней на
  учёбе.
- **S9 — худший день:** шорт на сутки в день с минимальной средней на учёбе.

### Исполнение и издержки
- Вход — по open первого бара окна, выход — по open бара после окна, то есть по close последнего
  бара. Одна сделка на каждое появление окна: S1–S6 — раз в сутки, S7–S9 — раз в неделю.
- Издержки на круг: 2 × (тейкер 0.055% + проскальзывание 0.02%) = **0.15% номинала**.
- **Фандинг — по фактическим событиям монеты.** В момент t позиция платит ставку × номинал: лонг
  платит при ставке > 0, шорт получает.
  - Позиция держится в t, если вход < t < выход.
  - Событие ровно в момент входа или выхода засчитывается, только если оно против позиции.
- Капитал — 1× номинал, без плеча, вся позиция в каждой сделке, без реинвестирования.
  - Годовые = сумма net-доходностей сделок за год.
  - Просадка — по кумулятивной сумме, в % капитала.
  - Шарп — по дневному P&L × √365.
- Для критерия годовых и просадки — портфель BTC/ETH 50/50.

## Критерий «кандидат» (всё сразу, на проверке 2024-01 … 2026-07)
1. Net > 0 в каждом из 5 отрезков проверки — отдельно у BTC и отдельно у ETH.
2. Эффект виден на обеих монетах в одну сторону: следует из п. 1, где окно и направление одни и те
   же.
3. У портфеля 50/50 годовых после издержек > 10% капитала, максимальная просадка < 25%.
4. **Поправка на 9 вариантов:** t-статистика дневного net-P&L портфеля на проверке > 2.54
   (Бонферрони 0.05/9, односторонний).

Если ни один вариант не прошёл — вердикт «не кандидат», семейство закрывается.

## Заморозка
Один раз оцениваются:
- вариант с лучшим Шарпом портфеля 50/50 на УЧЁБЕ среди S1–S9 — это «выбранный вариант»;
- плюс все, кто прошёл критерий на проверке.

Результат заморозки пишется отдельно. Он не превращает «не кандидата» в кандидата, но может
снять кандидата, если тот провалит заморозку.
