# Замер: пауза монеты+стороны после убыточного стопа (регистрация ДО прогона)

Дата: 2026-10-07. Повод — живые 06.10: три LONG подряд по PUMPFUN (#506, #509, #511) в
падающую монету, все −1R. Тормоз стороны (3 стопа / 6ч по всему вотчлисту) серию по
одной монете не ловит.

Живой журнал с 10.08 (наблюдение-повод, в критерий НЕ входит): сделки, открытые в
течение H часов после убыточного стопа той же монеты и стороны, против остальных:
H=12: exp +0.182 (n 16) vs +0.309; H=24: +0.137 (n 21) vs +0.325;
H=48: −0.005 (n 24) vs +0.364. n мало — отсюда только гипотеза.

## Правило
`simulate_portfolio(symbol_cooldown_hours=H)` (дефолт 0 — выкл): сигнал (решение в T =
dt + ТФ) пропускается, если у той же монеты и той же стороны (любой ТФ и сетап) был
выход по стопу с result_r < 0, известный к T (бар выхода закрыт: closed_dt + 1ч ≤ T),
и T − closed_dt ≤ H.

## Варианты (ровно два)
* C24 — H = 24ч; C48 — H = 48ч.

## Инструмент и база
Снимок прода с гейтом входа `data/cache5y/sig_prod_late_entry` (эталон n=5819, +358.1R
при M0), конфиг прода (1h+4h, 6226+LTF, min_stop 1.3, трейл 1.5/0.2, cap 6, тормоз
3/6ч, без тейка, удержание 168ч), живой судья. Издержки M1 (+0.080R/сделку), справочно M0.
Половины: TRAIN до 2025-07-28, OOS с 2025-07-28.

## Критерий (как у прошлых фильтров; вариант против базы, на ОБЕИХ половинах)
1. exp ≥ exp(база) + 0.03R; 2. exp выше 95-го перцентиля случайных подвыборок той же
длины из сделок базы (1000 раз); 3. n ≥ 30% базы; 4. DD ≤ DD(база).
Проходит → предлагаем владельцу. Проходят оба → берём C24, если C48 не лучше по exp на
обеих половинах. Не проходит ни один → фиксируем, H не перебираем.
