# Замер: выход «застрявшей» сделки через 12ч (регистрация 2026-10-30, ДО прогона)

## Повод
Задача 30.10: найти новые улучшения управления сделкой поверх прода с 27.10 и проверить два
лучших строго по регистрации. Кандидаты отбирались разведкой ТОЛЬКО на 5y H1 (сигналы до
2025-07-28, как «разведка на TRAIN» в прошлых замерах); 5y H2 и ротационная вселенная не
смотрелись. Разведка — по исполненным сделкам базы, портфель не пересимулировался; это НЕ
вердикты, а ранжирование. Инструмент — `scripts/research_judge.py`: исследовательская
реплика живого судьи на numpy (прод её не импортирует), сделка-к-сделке совпадает с
оригиналом на обоих наборах (4045 и 2732 сделки, все кортежи равны).

Строение базы на 5y H1 (n=3168): 1833 стопа −1R (58%), 1332 выхода трейлом (ср. +1.86R
брутто), 3 по потолку 168ч; издержки 0.148R/сделку, брутто exp +0.20R. 766 стопов (42%
проигравших, 24% всех сделок) — на самом баре филла (вход и стоп за один час). До +1R перед
стопом доходили лишь 16% проигравших (живой разбор 24.10 — 44%; на истории не подтверждается).

**Находка о модели (вне кандидатов).** Те же сделки H1 в окне, где есть 15m-бары
(2024-07-31…2025-07-27, n=1026), пересужены трейлом на 15m: средний победитель трейла
+1.835 → +1.606R, брутто exp +0.217 → +0.125R. Судья на 1h не видит откаты на 0.2R внутри
часа после нового максимума — трейл 0.2R на часовых барах выглядит лучше, чем исполнил бы
биржевой трейлинг. Вывод не делаем (разведка); это повод для отдельного замера реализма.

## Правило Z12
После бара филла правило проверяется ОДИН раз — на баре, открывшемся через 12ч после бара
филла (обычно 12-й бар после него): если за бары после бара филла (включая этот) лучший ход
в пользу сделки (high для LONG, low для SHORT) < +0.5R, позиция закрывается по close этого
бара (рыночный выход). Иначе — без изменений. Выход по застою считается стопом для тормоза
стороны (как выход по потолку 168ч). Трейл 1.5/0.2, стоп, потолок — как в проде.
Пороги 12ч и 0.5R не перебираем.

## Критерий (общий для обоих замеров 30.10)
1. На КАЖДОЙ из четырёх половин (5y H1, 5y H2, rot H1, rot H2): ΣR(вариант) > ΣR(база).
2. На каждой из четырёх половин: DD(вариант) ≤ DD(база).
3. Существенность: сумма приростов ΣR по четырём половинам ≥ +17.5R (5% суммарного ΣR
   базы 349.3R).
Порог exp +0.03R здесь не применяется: правило касается ~2% сделок, сдвинуть средний R
на 0.03 оно не может по построению; защита от шума — требование «все 4 половины» плюс
пункт 3. Диагностика (в вердикт не входит): число выходов по застою и парный прирост на
тех же сигналах в базе.

## Независимость

ячейки); независимы 5y H2, rot H1, rot H2. Других вариантов не запускаем.
