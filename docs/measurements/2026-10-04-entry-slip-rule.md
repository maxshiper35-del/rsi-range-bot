# Решающее правило: модель входа executor (регистрация 2026-10-04)

Вход — TRIGGER_MARKET по касанию entry (замер 31.08: пассивная лимитка проигрывает из-за
adverse selection). Бэктест закладывает слип 0.02% цены, но на быстрых альтах реальный
маркет-вход может стоить заметно больше. Правило задано ДО накопления выборки:

* Выборка: все исполненные входы executor с `created_at >= 2026-09-02T11:05Z` (эпоха
  триггер-маркета; первый ордер #434). Слип в R = ±(entry журнала − цена филла) / дистанция
  стопа, «+» = вошли лучше журнала.
* На 04.10: n=30 входов эпохи триггер-маркета, средний −0.080R (порог −0.10R при n ≥ 50).
* **Правило:** при n ≥ 50 и среднем слипе ≤ −0.10R модель входа пересматривается (замер
  альтернатив на паритетном кэше: агрессивная лимитка с ценой entry±k·ATR, ограничение
  входа по волатильности бара касания). Пока не выполнено — модель не трогаем.
* Отслеживание автоматическое: строка «Слип входа накопительно» в еженедельном отчёте
  executor админу (`execution_report`), при срабатывании — отдельная ⚠️-строка.

Почему −0.10R: эдж стратегии на тейкер-издержках +0.116R/сделку (5 лет); слип −0.10R
съедает его почти целиком — это граница, за которой торговать маркетом бессмысленно.
