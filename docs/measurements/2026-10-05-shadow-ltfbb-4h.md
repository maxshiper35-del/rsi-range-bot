# Проверка вперёд: LTF-BB на 4h в теневом режиме (регистрация 2026-10-05)

Решение владельца 05.10. На паритете с живым судьёй LTF-BB 4h в минусе на ОБЕИХ половинах
5-летки (TRAIN n=1127 exp −0.052R; OOS n=326 exp −0.021R) — самый крупный балласт. Гипотеза
найдена на тех же данных (диагностика по сетапам), поэтому проверяется ВПЕРЁД, на данных,
которых никто ещё не видел.

## Механика
`runtime.shadow_setups` (дефолт `LTF-BB@4h`): сигнал проходит все живые гейты (свежесть,
дедуп, кап, тормоз), записывается status='rejected' с флагом snapshot.shadow='setup_off' и судится тем
же живым судьёй в тень. Не публикуется, не исполняется на демо, не входит в публичную
стату, кап и тормоз (живой портфель ведёт себя так, будто сетап выключен). Итог: /shadow.

## Правило решения (фиксировано заранее)
Оценка — когда выполнены ОБА условия: ≥ 3 месяцев с 2026-10-05 и ≥ 60 закрытых теневых
сделок LTF-BB@4h.
* exp ≤ 0 → выключить насовсем (убрать из теней, сетап на 4h не генерировать).
* exp ≥ +0.05R → вернуть в публикацию.
* между → продолжать тень ещё 3 месяца, затем то же правило.
Пока решения нет — сигналы этой пары не публикуются (статус-кво = тень).
