## 2. Данные
* **База — прод с 27.10.**
  - Только 1h-сигналы; живой судья на 1h; трейл 1.5R/0.2R без тейка; удержание 168ч.
  - Портфель: cap 6 на сторону, тормоз 3 стопа за 6ч, дедуп.
  - Издержки M2′: комиссия 0.055% × 2, слип 0.15%, фандинг 0.125 б.п. за бар.
  - Сетки сделок воспроизведены оригинальным путём `simulate_portfolio` бит-в-бит:
    5y 3168/+169.8 и 877/+59.1; ротация 1292/−72.3 и 1440/+192.7.
* **Сделки замера** — сделки базового портфеля, у которых бар филла не раньше 2024-07-31
  (начало кэша 15m), парно:
  - **W1** — 9 монет, часть 5y H1 (решение < 2025-07-28), n=1026;
  - **W2** — 9 монет, 5y H2, n=877;
  - **rot H1** — ротационная вселенная, решение < 2025-10-24, n=1292;
  - **rot H2** — ротационная вселенная, решение ≥ 2025-10-24, n=1440.
* **Мелкие бары — только Bybit linear**, тот же источник, что у журнала.
  - 15m: для 9 монет — кэш `data/cache5y/*_15m.csv`; для ротации — агрегат 1m по
    15-минутным границам.
  - 1m: публичный kline Bybit на окно каждой сделки [открытие бара филла 1h; конец бара
    выхода 1h). Кэш — `data/cache_tf/m1/`, в git не идёт.
  - Почему окна хватает: уровень непрерывного трейла в любой момент не ниже часового
    (пик виден раньше), поэтому мелкая модель выходит не позже часовой. Исключение — стоп
    на баре филла, если касание стопа было раньше касания входа. Для таких сделок окно
    продлевается докачкой.
* **Покрытие.** Сделка без мелких баров в окне или без касания входа внутри часа филла
  исключается из парного сравнения у обеих моделей. Доля таких сделок — в отчёте; при
  покрытии половины < 90% — флаг.

## 3. Модели (вход, стоп, активация и отступ одинаковы — меняется только оценка трейла)
* **M1h — журнал.** Живой судья на 1h: стоп бара по уровню с прошлого бара; трейл
  подтягивается на закрытии бара, не на баре филла. Gross R и издержки — из реплики
  `scripts/research_judge.py`, она совпадает с оригиналом сделка-к-сделке.
* **Мелкая модель (15m и 1m).**
  - **Путь цены внутри бара:** бычий (C ≥ O) — O→L→H→C, медвежий — O→H→L→C; между барами
    — C→O следующего. Границы: все бары O→L→H→C и все бары O→H→L→C.
  - **Филл** — первое касание входа на пути внутри часа филла журнала.
  - **Стоп** −1R действует с момента филла, выход по уровню стопа, как у журнала.
  - **Трейл** после активации следует за экстремумом непрерывно; выход по уровню
    «экстремум − 0.2R».
  - **Потолок** — close последнего мелкого бара в часе филл + 168ч, как у журнала.
  - **Издержки** — та же формула. Фандинг — по целым часам от открытия бара филла 1h до
    открытия часа выхода.
  - **J — правило журнала:** активация разрешена только после конца часа филла.
    Диагностическая модель: отделяет эффект отката внутри часа от правила бара филла.
  - **E — как e5 в проде с 30.10:** активация разрешена с момента филла. Это основная
    реалистичная модель: executor e5 ставит трейл по стриму через секунды после прохода
    +1.5R.

## 4. Паритет (до вердикта; не сошлось — стоп, не интерпретируем)
1. База оригинальным путём — числа раздела 2 бит-в-бит.
2. Реплика судьи с пустым правилом совпадает с базой сделка-к-сделке.
3. Мелкий судья в дискретном режиме (обновление трейла на закрытии бара, стоп по уровню

   gross R и бар выхода M1h для всех сделок.
4. Данные:

   - агрегат 1m→15m совпадает с 15m-кэшем 9 монет;
   - доля расхождений — в отчёте; > 1% — флаг.

## 5. Метрики (по каждой половине, для M1h, J15, E15, J1m, E1m)
* По каждой модели:
  - n;
  - R/сделку gross и net;
  - ΣR net;
  - макс. просадка кумулятивного net R по времени выхода;
  - доля выходов по трейлу.
* Переоценка трейл-выхода: среднее (R_1h − R_мелк) по сделкам, которые в M1h вышли трейлом.
* Разложение Δ по классу исхода в M1h: трейл, стоп, потолок.
* **Основная метрика:** Δ = net R/сделку(E1m) − net R/сделку(M1h) на одних и тех же
  сделках (покрытие 1m).

## 6. Критерий (записан до прогона)
**Вопрос 1 — модель журнала, по Δ на четырёх половинах (W1, W2, rot H1, rot H2):**

| вердикт | условие |
|---|---|
| «адекватна» | \|Δ\| ≤ 0.02R/сделку на всех 4 половинах |
| «завышает» | Δ ≤ −0.03R/сделку хотя бы на 3 из 4 половин |
| «занижает» | Δ ≥ +0.03R/сделку хотя бы на 3 из 4 половин |
| «неоднозначно» | иначе |

Устойчивость. Тот же вердикт пересчитывается на границах порядка внутри минуты (все бары
O→L→H→C и все O→H→L→C). Если класс меняется — флаг «чувствителен к порядку внутри минуты»;
основной вердикт остаётся по правилу цвета свечи.

Вердикт по 15m (E15) — для сравнения, в решение не входит.

**Вопрос 2 — плюс по реалистичной модели (E1m net):**

| вердикт | условие |
|---|---|
| «плюс сохраняется» | на каждой половине, где M1h > 0, E1m > 0, и сумма net R E1m по 4 половинам > 0 |
| «плюс исчезает» | хотя бы 2 половины, плюсовые в M1h, в E1m ≤ 0, либо сумма ≤ 0 |
| «на грани» | иначе |

## 7. Что предлагается владельцу при каждом исходе (прод сам не меняется)
* **«Адекватна».** Модель журнала не трогаем.
  - Разрыв с демо — это исполнение (обрывы сети Mac, демо-стакан VST).
  - Копитрейдинг и реальные деньги — после подтверждения e5 на демо (раздел 8).
* **«Завышает» + «плюс сохраняется».**
  - Для НОВЫХ сигналов судить трейл по 1m: версия правила в снапшоте, историю не трогаем.
  - Показать второй трек и пересчитать помесячный бэктест в мини-приложении по
    реалистичной модели.
  - Цифры для реальных денег — только реалистичные.
* **«Завышает» + «плюс исчезает» или «на грани».**
  - Журнальный итог не называть достижимым.
  - Копитрейдинг и реальные деньги не запускать.
  - Параметры трейла на 1m — ОТДЕЛЬНЫЙ замер с регистрацией и полной пересимуляцией
    портфеля (здесь не перебираются).
* **«Занижает».** Модель журнала консервативна, менять нечего.
* **«Неоднозначно».** Оставить как есть. Повторить сверкой с живыми трейл-выходами (раздел 8).

## 8. Сверка с реальными выходами демо (диагностика, в вердикт не входит)
`scripts/trail_demo_recon.py` по каждой закрытой сделке executor (e4/e5) печатает три R:
* журнала;
* модели E на 1m Bybit;
* демо (филл и закрытие BingX, без комиссий и с ними).

Сейчас его прогоняем на том, что есть; полную сверку — когда трейл-выходов e5 будет ≥ 60.
Модель E считается подтверждённой исполнением, если на трейл-выходах среднее
(демо − E1m) лежит в пределах ±0.1R.
