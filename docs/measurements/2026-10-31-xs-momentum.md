# Замер: кросс-секционный моментум на перпетуалах Bybit (регистрация 2026-10-30, ДО прогона)

Этот текст записан и закоммичен до первого прогона бэктеста. Результаты добавляются ниже
отдельным коммитом, в правила ничего не дописывается.

## 0. Зачем

Замер «реализм трейла» (2026-10-30-trail-realism.md) показал: при реальном исполнении
нынешняя стратегия бота после издержек в минусе. Ищем рабочую стратегию из другого
семейства.

Кросс-секционный моментум — документированный фактор крипторынка: монеты с большей
доходностью за последние 1–4 недели в среднем обгоняют остальные следующую неделю
(Liu, Tsyvinski, Wu, «Common Risk Factors in Cryptocurrency», J. Finance 2022).

Вопрос: остаётся ли эффект на перпетуалах Bybit после тейкерской комиссии, проскальзывания
и реального фандинга? И можно ли раздавать его подписчикам раз в неделю?

## 1. Данные

* Дневные свечи 1D (UTC) **всех** USDT-перпетуалов Bybit, когда-либо торговавшихся.
  * Список символов: текущие инструменты API v5 плюс индекс публичного архива сделок
    `public.bybit.com/trading/` — 1 136 символов на 30.10.2026.
  * Делистнутые входят. Их свечи API отдаёт по имени: SRMUSDT и LUNAUSDT проверены.
* Фандинг: `/v5/market/funding/history`, по символам, которые хоть раз попадали во вселенную.
* Скрипт данных: `scripts/research_xsmom_fetch.py`. Кэш: `data/cache_research/xsmom/`, не в git.

## 2. Участки

| участок | даты (UTC) | для чего |
|---|---|---|
| учёба | 2021-01-01 … 2023-12-31 | **только здесь** выбираются параметры |
| проверка | 2024-01-01 … 2026-07-31 | критерий; половины V1 = 2024-01-01…2025-03-31, V2 = 2025-04-01…2026-07-31 |
| заморозка | 2026-08-01 … последняя полная неделя | одна финальная оценка уже выбранного варианта, отдельной строкой |

Неделя относится к участку по дате её ребалансировки.

## 3. Правила стратегии

**Ребалансировка:** каждый понедельник 00:00 UTC (момент t).

**Вселенная на дату t:**
* символ торгуется: есть дневные закрытия, последнее не раньше t − 1 день;
* возраст ≥ 35 дней (свечей ≥ 35) — все lookback определены, свежие листинги-пампы отсечены;
* рейтинг по среднему дневному обороту (USDT) за 30 дней до t;
* **N = 50** верхних. Если подходящих меньше 50 — берутся все. Если меньше 20 — неделя
  пропускается (flat) во всех вариантах одинаково;
* без стейблкоинов (USDC, BUSD, DAI, TUSD, FDUSD, USDE и подобных). BTCUSDT — обычный участник.

**Сигнал:** r = close(t − s) / close(t − s − 7·L дней) − 1, где L ∈ {1, 2, 4} недели,
s ∈ {0, 1} день — пропуск последнего дня против краткосрочного разворота.

**Портфель (семейство A, лонг-шорт):** лонг K лучших по r, шорт K худших, K ∈ {3, 5, 10}.
* Равные веса.
* Экспозиция: лонг-нога 0.5, шорт-нога 0.5 от капитала, то есть gross 1× без плеча.
  Доходность и просадка растут линейно с плечом, Шарп от него не зависит.

**Портфель (семейство B, лонг против BTC):** лонг K лучших (без BTC) с весом 0.5 против
шорта BTC с весом 0.5. Та же сетка L × s × K.

**Исполнение:** по close(t) — момент, когда известен сигнал (s = 0). Вес держится до
close(t + 7 дней). Внутри недели веса дрейфуют вместе с ценой.

**Делистинг внутри недели:** позиция закрывается по последнему доступному закрытию, дальше
до конца недели в кэше.

**Издержки:**
* комиссия — тейкер 0.055% от проторгованного номинала: Bybit, базовый уровень, линейные
  контракты;
* проскальзывание (полуспред + малый импакт) по рангу оборота на дату сделки:
  * ранг 1–20 — 0.02%;
  * ранг 21–50 — 0.05%;
  * ранг > 50 — 0.10% (нужно для проверки на N = 100).

  Обоснование: спред топ-20 Bybit ≈ 1–2 б.п., у средних монет 3–10 б.п. Размер позиции
  подписчика мал по сравнению с оборотом, импакт пренебрежим;
* проторгованный номинал на ребалансировке = Σ|w_new − w_old_после_дрейфа|; вход в первую
  неделю тоже считается;
* фандинг: позиция с весом w платит −w × Σ ставок фандинга за метки времени в (t, t+7д].
  Лонг платит при положительной ставке, шорт получает. Номинал — на момент ребалансировки.

## 4. Метрики (net, недельный ряд)

* годовая доходность: (Π(1 + r))^(52/n) − 1;
* Шарп: mean / std × √52;
* максимальная просадка по сложной кривой;
* средний недельный оборот (односторонний);
* доля прибыльных недель;
* бета к BTC: МНК недельных доходностей портфеля на недельную доходность BTCUSDT;
* для справки — gross-Шарп до издержек.

## 5. Сетка и правило выбора

* Семейство A: L {1, 2, 4} × s {0, 1} × K {3, 5, 10} = 18 вариантов.
* Семейство B: та же сетка = 18 вариантов.
* **Всего опробуется 36 вариантов.** Перечисленные ниже проверки устойчивости в выборе не
  участвуют.
* **Выбор:** в каждом семействе — вариант с наибольшим net-Шарпом на **учёбе**. Выбор
  фиксируется в выводе скрипта до печати чисел проверки.
* Таблица проверки по всем 36 вариантам печатается в приложении только для прозрачности,
  для выбора она не используется.

## 6. Критерий «кандидат» (для выбранного варианта каждого семейства)

1. На проверке (2024-01 … 2026-07) net-Шарп > 1.0.
2. Net-доходность > 0 в каждой половине проверки, V1 и V2.
3. Соседи — все варианты, отличающиеся одним параметром на один шаг сетки (L ±1 шаг,
   s ↔, K ±1 шаг). У всех соседей net-доходность на проверке > 0.
4. Без двух главных вкладчиков: на проверке два символа с наибольшим суммарным net-вкладом
   исключаются из вселенной, портфели строятся заново. Net-Шарп > 0.5 и доходность > 0.

Прошёл все четыре пункта — **кандидат**. Тогда одна оценка на заморозке. Около 13 недель —
это шум, оценка нужна, чтобы увидеть катастрофу, а не чтобы подтвердить.

Проверки устойчивости, только для отчёта:
* N = 30 и N = 100;
* исполнение с задержкой на 1 день (close(t + 1д) → close(t + 8д)) — это ближе к подписчику
  из Telegram;
* дробление по годам.

## 7. Telegram

Отдельно оцениваем раздачу подписчикам: сообщение раз в неделю «лонг X, Y, Z / шорт A, B, C».

* Минимальный депозит: 2K позиций, у каждой минимальный ордер Bybit и шаг количества.
* Чувствительность к задержке исполнения на 1 день.
* Ёмкость: все подписчики входят одновременно.
