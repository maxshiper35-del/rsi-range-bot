# Замер модели входа на паритете с живым судьёй (регистрация ДО прогона)

Дата: 2026-10-05. Замер 31.08 («маркет по касанию лучше пассивной лимитки») сделан на
оптимистичной модели. На демо реальный слип маркет-входа −0.080R/сделку (n=30, эпоха
триггер-маркета с 02.09) — больше всего края стратегии на паритете (+0.014R).

## Инструмент
`simulate_portfolio(live_judge_bars=…)`, конфиг прода (1h+4h, 6226+LTF, min_stop 1.3,
трейл 1.5/0.2, cap 6, тормоз 3/6ч), 2021-07..2026-07, половины TRAIN/OOS (граница
2025-07-28). Филл «сквозь уровень» — новый необязательный параметр живого судьи
`fill_through_frac` (дефолт 0 = поведение прода не меняется).

## Варианты (ровно четыре)
* M0 `маркет-модель`: касание, тейкер 0.055%×2, слип 0.02% — текущий бэктест (справочно).
* M1 `маркет-реальность`: как M0 + 0.080R на сделку (замеренный слип демо). **Бейслайн.**
* L5 `лимитка сквозь 5%`: филл только если цена прошла entry на 5% дистанции стопа;
  мейкер-вход 0.02% + тейкер-выход 0.055% (среднее 0.0375%/сторона), слип 0.01%.
* L10 `лимитка сквозь 10%`: то же, проход 10%.

## Критерий (вариант L* против M1, на ОБЕИХ половинах)
1. ΣR >= ΣR(M1) + 10R; 2. exp >= exp(M1) + 0.02R; 3. DD <= DD(M1).
Проходит — предлагаем владельцу перевести executor на лимит-вход. Не проходит ни один —
фиксируем: при реальном слипе край отрицателен/нулевой, реальные деньги не ставить
до нового источника края.

## РЕЗУЛЬТАТ (2026-10-06) — лимит-вход НЕ ПРИНЯТ; при реальном слипе край отрицательный

M0 воспроизводит бэктест (n=5309, +73.3R).

| вариант | TRAIN n / Σ / exp / DD | OOS n / Σ / exp / DD |
|---|---|---|
| M0 маркет-модель (справочно) | 4117 / +0.6 / +0.000 / 110.8 | 1192 / +72.7 / +0.061 / 32.8 |
| **M1 маркет-реальность (база)** | 4117 / −328.8 / −0.080 / 346.2 | 1192 / −22.6 / −0.019 / 65.5 |
| L5 лимитка сквозь 5% | 4386 / −665.4 / −0.152 / 669.3 | 1306 / −127.4 / −0.098 / 129.5 |
| L10 лимитка сквозь 10% | 4297 / −859.6 / −0.200 / 861.2 | 1287 / −175.8 / −0.137 / 175.8 |

Вердикт L5, L10: не принято (хуже базы по всем трём пунктам на обеих половинах).

Что это значит:
* Лимитка проигрывает из-за отбора против себя: «сквозь уровень» исполняются в основном
  сделки, которые продолжают идти против входа, а лучшие (касание и сразу разворот)
  остаются без филла. Экономия комиссии (~0.02% на вход) этого не покрывает. Вывод
  31.08 «маркет лучше лимитки» подтверждён и на правильной модели.
* Главное: с реальным слипом демо (−0.080R) стратегия минусовая на обеих половинах
  (TRAIN −329R, OOS −23R). Края у текущей стратегии после реального исполнения нет.
  Реальные деньги не ставить; executor остаётся на демо. Улучшение возможно только
  из нового источника информации, не из подкрутки входа/выхода.
* Оговорка: слип −0.080R замерен на n=30 (демо, эпоха триггер-маркета). Правило
  `slip_rule_verdict` продолжает копить n≥50; если живой слип окажется заметно меньше,
  M1 пересчитывается тем же скриптом с новым числом (без смены критерия).
