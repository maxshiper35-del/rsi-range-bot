# Правила проверки вперёд (регистрация 2026-10-24, ДО накопления данных)

Три решения октября проверяются на будущих сделках. Пороги записаны здесь до данных и не
меняются задним числом; бот каждую неделю присылает админу прогресс
(`app/brain/forward_check.py`). Решение принимает владелец; правило — подсказка, а не автомат.

## 1. Гейт «вход уже пройден» (включён 2026-10-06 22:00 UTC)
Сравнение: опубликованные сигналы, созданные после включения (закрытые, с исходом), против
отсечённых гейтом (тень `late_entry`, закрытые).
* Готовность: ≥ 40 закрытых в тени И ≥ 6 недель с включения.
* exp(тень) ≥ exp(опубликованные) — гейт не помогает → пересмотреть (вероятно, выключить).
* exp(тень) < exp(опубликованные) — гейт работает → оставить.

## 2. Тень LTF-BB@4h (с 2026-10-05)
То же правило, что в /shadow (решение владельца 05.10):
* Готовность: ≥ 60 закрытых И ≥ 3 месяцев.
* exp ≤ 0 → выключить насовсем; exp ≥ +0.05R → вернуть в публикацию; между — продолжать.

## 3. Executor (демо) → живые деньги
Только сделки, созданные после трейла на бирже (2026-10-19 23:30 UTC); реальный R — по
ценам исполнения из трейдов биржи (исправлено 24.10).
* Готовность: ≥ 60 закрытых.
* Кандидат на живые деньги (маленький размер, решение владельца), если ВСЁ:
  реальный exp ≥ +0.05R; реальная макс. просадка ≤ 20R; средний отрыв от журнала
  ≥ −0.05R на сделку.
* Иначе — продолжать демо; при реальном exp ≤ 0 на ≥ 60 сделках — пересмотр стратегии.
