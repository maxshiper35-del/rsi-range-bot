# Замер: оверлей риска (размер позиции), регистрация критерия ДО прогона

Дата регистрации: 2026-10-04. Мотив: эдж тонкий (+0.116R/сделку на 5 годах), а боль —
форма кривой (макс. просадка 50.3R, 96 дней). Отбор сигналов НЕ меняется — только вес
каждой сделки. Поэтому замер — чистая пост-обработка сделок бейслайна: портфельные гейты
(cap по числу, тормоз по стопам, дедуп) от размера не зависят.

## Данные
Сделки бейслайна `scripts/measure_bias_gate.py` (живая конфигурация, тейкер-издержки,
паритетный кэш, 9 символов, 1h+4h): вся история n=5353 (+622.4R, DD 50.3R); половины
TRAIN (до 2025-07-28) и OOS (с 2025-07-28) — отдельные прогоны.

## Варианты (ровно два, других не запускаем)
* **V1 «корреляционный»**: вес = 1/sqrt(1+k), где k — число сделок ТОЙ ЖЕ стороны,
  уже находящихся в позиции в момент филла (fill_dt другой <= fill_dt этой < exit_dt другой).
  Логика: одновременные позиции в одну сторону на крипте почти один риск.
* **V2 «просадочный тормоз»**: вес = 0.5, если в момент филла эквити по закрытым ДО филла
  сделкам (в R бейслайна) ниже своего максимума на 15R и больше; иначе 1.0.

Решение принимается только по информации, доступной в момент филла (без заглядывания).

## Сравнение при равном среднем риске
Веса варианта нормируются так, чтобы средний вес по половине = 1.0 (иначе любой вариант
«уменьшает просадку» просто уменьшением риска). Метрики по нормированным весам:
ΣR, макс. просадка по эквити в порядке закрытия, ΣR/DD.

## Критерий (для КАЖДОГО варианта отдельно, на ОБЕИХ половинах)
1. DD варианта <= 0.85 × DD бейслайна (просадка минимум на 15% меньше).
2. ΣR варианта >= 0.95 × ΣR бейслайна (не более 5% потери суммы).

Оба пункта на обеих половинах -> предлагаем владельцу как правило размера для executor
(включает владелец; для сигналов подписчикам — как рекомендация «половинный риск при
N открытых в одну сторону»). Иначе — ОТВЕРГНУТО, в «не перепредлагать».
Поправка на множественность: вариантов два, порог 15% выбран заранее; если проходит только
один вариант на одной половине — это шум, не принимаем.
