# Перепроверка старых решений на паритете с живым судьёй (регистрация ДО прогона)

Дата: 2026-10-05. Все решения ниже принимались на оптимистичной модели `_simulate_open`
(стоп на баре филла не засчитывался, 4h судились 4h-барами, выход по тейку). Теперь
мерим тем же инструментом, что и бэктест: `simulate_portfolio(live_judge_bars=…)`.

## Бейслайн = текущий прод
1h+4h, сетапы 6226+LTF, min_stop_pct 1.3, трейлинг активация 1.5R / дистанция 0.2R,
cap 6, тормоз 3/6ч, дедуп, тейкер 0.055% + слип 0.02% + фандинг 0.125 bps/ч.
Должен совпасть с app/backtest_monthly.json (n=5309, +73.3R).

## Варианты (ровно пять, других не запускаем; каждый меняет ОДИН параметр)
* V1 `1:1 вкл`   — сетапы 6226+1:1+LTF (решение 09.08 «выключить 1:1»)
* V2 `trail 0.3` — дистанция трейлинга 0.3R (решение «0.2 вместо 0.3»)
* V3 `act 1.0`   — активация трейлинга 1.0R (оставлено 1.5 как «неотличимо»)
* V4 `stop 1.0`  — min_stop_pct 1.0
* V5 `stop 1.6`  — min_stop_pct 1.6

## Критерий (тот же, что у замера «только 1h»; на ОБЕИХ половинах:
TRAIN до 2025-07-28, OOS с 2025-07-28)
1. ΣR варианта >= ΣR бейслайна + 10R
2. exp варианта >= exp бейслайна + 0.02R
3. DD варианта <= DD бейслайна

Все три на обеих половинах -> вариант предлагается владельцу. Иначе текущее значение
остаётся (статус-кво не требует доказательств — менять его требует). Пять сравнений:
строгий порог на обеих половинах — защита от ложного срабатывания.
