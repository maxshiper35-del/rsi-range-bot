# Замер: минимальный стоп на реалистичной модели издержек (регистрация ДО прогона)

Дата: 2026-10-20. Повод — демо-executor (75 закрытых): реальный итог −29.1R против −3.3R
журнала. Вход после гейта (n=31): слип в среднем −0.201% цены (медиана −0.121%), при
медианном стопе 2.23% → −0.114R/сделку. Слип примерно постоянен в % цены, значит в R он
обратно пропорционален ширине стопа: 1.3% → −0.155R, 2% → −0.10R, 3% → −0.067R.
Прежние замеры брали слип 0.02% на круг (+ плоские 0.08R в M1) — узкие стопы были
в выгодном положении. Решение «min_stop 1.3%» (25.07, перепроверено 05.10/06.10) принято
на нереалистичной модели издержек.

## Модель издержек M2 (реалистичная, пропорциональная)
`simulate_portfolio(slippage_pct=0.25)` — суммарный слип на круг в % цены (вход 0.20% —
замер демо; выход стоп-ордером 0.05% — допущение, проверим по трейлу на бирже с 20.10),
тейкер 0.055%×2, фандинг 0.125 б.п./бар, без плоской добавки. Справочно — M0 (слип 0.02%)
и чувствительность M2' (слип 0.15% — медиана входа + выход), в вердикт не входят.

## Варианты (ровно два; гейт min_stop_pct — гейт движка ДО выбора кандидата)
* S2 — `dump_signals --prod --set min_stop_pct=2.0` → data/cache5y/sig_prod_late_entry_stop20
* S3 — `--set min_stop_pct=3.0` → data/cache5y/sig_prod_late_entry_stop30
База — data/cache5y/sig_prod_late_entry (прод: гейт входа entry, min_stop 1.3).

## Инструмент
Конфиг прода (1h+4h, 6226+LTF, гейт входа, трейл 1.5/0.2, cap 6, тормоз 3/6ч, без тейка,
удержание 168ч), живой судья. Половины TRAIN до 2025-07-28 / OOS с 2025-07-28.

## Критерий (как у параметров в перепроверке 05.10; вариант против базы, ОБЕ половины, M2)
1. ΣR ≥ ΣR(база) + 10R; 2. exp ≥ exp(база) + 0.02R; 3. DD ≤ DD(база).
Проходят оба → берём меньший стоп (S2), если S3 не лучше его по ΣR на обеих половинах.
Проходит → предлагаем владельцу. Не проходит ни один → 1.3 остаётся; пороги не перебираем.
