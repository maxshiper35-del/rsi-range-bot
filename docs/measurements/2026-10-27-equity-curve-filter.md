# Замер: фильтр режима по собственной кривой стратегии (регистрация 2026-10-27, ДО прогона)

## Повод
Замер ротационного вотчлиста (2026-10-24-rotating-universe.md): результат решает режим
рынка — 4 квартала подряд минус (2024Q4–2025Q3), затем 4 плюс (2025Q4–2026Q3), знак
одинаков во всех вариантах и почти во всех компонентах. Гипотеза: режимы длятся неделями,
поэтому недавний результат самой стратегии предсказывает ближайший.

## Правило EC(N)
Сигнал торгуется, если exp последних N сделок базы (той же стратегии без фильтра),
ЗАКРЫТЫХ к моменту решения (выход ≤ решение − 1ч), ≥ 0; иначе — в тень (не торгуется,
но его исход входит в окно — фильтр смотрит на стратегию, а не на себя). R окна — в той
же модели издержек, что и оценка (M2′). Первые N сделок — торгуются (окно не набрано).
Упрощение: фильтр — подмножество сделок базового портфельного прогона (освобождённые
слоты cap не переиспользуются) — консервативно для фильтра.

## Варианты (ровно два)
* EC50 — N = 50; EC100 — N = 100.

## Данные и издержки
* Главные — 5 лет, 9 монет: снимок прода sig_prod_late_entry (LTF-BB@4h в тени), конфиг
  прода, живой судья, **M2′ (слип 0.15%)**. Половины TRAIN < 2025-07-28 ≤ OOS.
* Подтверждение (в вердикт не входит): 2-летний ротационный A.

## Критерий (фильтр; вариант против базы, M2′, ОБЕ половины 5 лет)
1. exp ≥ exp(база) + 0.03R; 2. exp выше 95-го перцентиля exp случайных подвыборок сделок
базы того же размера (1000, seed 0); 3. n ≥ 30% базы; 4. DD ≤ DD(база); 5. ΣR ≥ ΣR(база).
Проходят оба → EC50, если EC100 не лучше по exp на обеих половинах. Не проходит ни один —
фиксируем, N не перебираем. Принятие — решение владельца.
