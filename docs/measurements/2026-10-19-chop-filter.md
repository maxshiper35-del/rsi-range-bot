# Замер: фильтр «пилы» по эффективности движения (регистрация ДО прогона)

Дата: 2026-10-19. Повод — неделя 12–18.10: 28 закрытых, −10.9R, 6 побед; в минусе и
опубликованные, и тени (late_entry −8.3R / 20, LTF-BB@4h −6.1R / 18) — минус потока, не
одного сетапа. Рынок — «пила»: BTC по дням −2.3 / +1.6 / −1.8 / +0.7 %, дневной диапазон
ETH 5–6%. Ретрейсмент-вход после слома структуры в боковике без направления ловит ложные
сломы. В бэктесте прода такие недели (≤ −10R) — 6% недель (15 из 262).

## Признак
Коэффициент эффективности Кауфмана по 4h-закрытиям: ER = |C_t − C_{t−42}| / Σ|C_i − C_{i−1}|
за 42 бара (7 суток). Только 4h-свечи, закрытые к моменту решения T (dt + ТФ).
Точечный ранг ER среди значений того же ряда за (T − 180 суток, T] — средний ранг; меньше
500 точек — признак не определён, сигнал проходит.

## Варианты (ровно два, порог задан здесь)
* R1 `пила рынка`: ранг ER **BTC** < 1/3 → пропустить ВСЕ сигналы этого решения.
* R2 `пила монеты`: ранг ER **своей монеты** < 1/3 → пропустить сигнал.
Фильтр отсекает все кандидаты бара одинаково, поэтому его можно применять к снимку
сигналов после выбора кандидата (без пересъёма).

## Инструмент и база
Снимок прода `data/cache5y/sig_prod_late_entry` (эталон n=5819, +358.1R при M0), конфиг
прода, живой судья, издержки M1 (+0.080R/сделку), справочно M0; половины TRAIN до
2025-07-28 / OOS с 2025-07-28.

## Критерий (как у прошлых фильтров, на ОБЕИХ половинах)
1. exp ≥ exp(база) + 0.03R; 2. exp выше 95-го перцентиля случайных подвыборок той же
длины из сделок базы (1000 раз); 3. n ≥ 30% базы; 4. DD ≤ DD(база).
Проходит → предлагаем владельцу (сначала в тень). Не проходит → фиксируем, порог не
перебираем.
