# Мега-план: до профессионального уровня (2026-07)

Источник: deep-research 2026-07-10 — 103 агента, каждое утверждение проверено 3 независимыми
скептиками против первоисточников (доки Cornix/Telegram, живые прайс-страницы, Myfxbook KB).
Ниже — только выжившие после верификации факты, смапленные на текущее состояние бота.
Связь с гейтами роста: K-вехи из `TOP_LEVEL_PLAN.md` действуют (K2 = ≥25–30 закрытых сделок
+ ≥3 платящих — до него не жечь деньги на трафик).

## Что показал рынок (проверенные факты)

1. **Cornix — де-факто стандарт авто-исполнения** из Telegram-каналов: юзер подключает биржу
   по API-ключам, бот копирует entry/TP/SL из интегрированных каналов. 11 бирж (фьючерсы — 9,
   вкл. Bybit). Cornix-совместимость **продаётся как ключевой дифференциатор платного тира**
   (WolfX VIP: free-канал без автоматизации). Планка riск-менеджмента подписчика: 5 типов
   трейлингов, портфельный кэп, авто-отмена протухших сигналов (TP/SL до fill).
2. **Stars-подписки нативные — строго 30 дней** (другой период невозможен), но: платный
   invite-link приватного канала **автоматически добавляет юзера после оплаты и удаляет при
   истечении** — гейтинг доступа полностью платформенный, DM-рассылка не обязательна.
3. **Mini Apps** поддерживают Stars-платежи и подписочные тиры внутри приложения; бот с main
   Mini App + Stars-платежами может попасть в **Mini App Store** (канал дистрибуции).
4. **Нативная партнёрская программа Telegram** (`commission_permille`): любой юзер/канал
   продвигает бота и получает комиссию со Stars-покупок приведённых. Готовый реферальный
   механизм без своей инфраструктуры. Нюанс: комиссия только на Stars-транзакции ВНУТРИ бота —
   наши инвойсы именно такие. Это закрывает задачу 23 (рефералка) почти бесплатно.
5. **Paid media** (`sendPaidMedia`, фото/видео за Stars + `purchased_paid_media` апдейт) —
   поштучная продажа сигнал-карточек. Только фото/видео — а у нас **уже есть PNG-карты
   сигналов**: прямое совпадение со стеком.
6. **Ценовой бенчмарк**: CoinCodeCap Signals — $99/мес + $729 lifetime, 7-дневный money-back,
   винрейт 67% self-reported на 269 сигналах с пометкой «Losing trades included». Наши
   1000⭐ (~$20)/мес — в 5 раз дешевле рынка.
7. **Эталон доверия — Myfxbook**: публикация трек-рекорда гейтится верификацией истории
   против данных брокера. Наш аналог уже есть (скоринг только по OHLCV биржи + CSV+sha256) —
   его нужно ДОНЕСТИ, а не построить.
8. Анти-паттерны (жалобы юзеров): перерисовка истории, скрытие лоссов, спам, накрученные
   винрейты. Мы построены наоборот — это позиционирование, его надо продавать. Осторожно:
   FCA выносит предупреждения сигнальным сервисам за неавторизованные финансовые промо (кейс
   WolfX, июнь 2025) — дисклеймеры и «не финсовет» не убирать никогда.

## Волны исполнения

### Волна 1 — «Cornix-ready + нативная монетизация» (сейчас; дёшево, конверсия)
1. **Верифицировать Cornix-блок с реальным Cornix и включить** (`cornix_block_enabled` уже
   в коде за флагом). Зарегистрировать канал как signal provider (Signal Integration),
   проверить парсинг на тестовом канале. Автопост «сигнал отменён» (expired) у нас уже есть —
   совместим с Cornix-моделью протухания.
2. **Нативная партнёрка Stars** (`commission_permille` через BotFather): комиссия ~10–20%
   с приведённых Stars-платежей. Пост в канал + строка в /help. Закрывает задачу 23.
3. **Paid media как третий тариф**: разовый сигнал-пост (PNG-карта + подпись) за N⭐ для
   не-подписчиков — «попробовать один сигнал» без подписки. Использует готовый рендер.
4. **Money-back политика** (7 дней, как у бенчмарка) — текст в /subscribe + ручной /refund
   через админа. Дёшево, сильный якорь доверия.

### Волна 2 — «VIP-канал вместо DM» (после стабилизации волны 1)
5. **Приватный VIP-канал со Stars-subscription invite-link**: платформа сама добавляет после
   оплаты и удаляет при истечении. Меньше трения, чем DM (боты в DM легко мьютятся); DM
   остаётся для тех, кто выбрал. Наша кастомная подписка (paid_until) продолжает работать
   для USDT/промо; нативная — параллельный рельс строго 30 дней.
6. **Ценовая лестница**: пробный 10⭐/5ч (есть) → месяц 1000⭐ (есть) → **годовой/lifetime**
   (задача 22; бенчмарк $729 lifetime) — только разовым платежом (нативные Stars-подписки
   длиннее месяца невозможны — проверено в доках).

### Волна 3 — «Mini App дашборд» (после K2; крупная ставка)
7. **Main Mini App**: живой PnL-дашборд (наш live-board + stats_by_setup + карточки) как TWA,
   Stars-платежи внутри, заявка в Mini App Store. Это самый большой кусок (фронтенд), делать
   когда есть кому его показывать (K2: ≥3 платящих, ≥25 закрытых сделок).
8. **Публичная страница верификации** (расширение задачи 29): CSV+sha256+скрипт проверки
   одним кликом — Myfxbook-паттерн «сверено с биржей» как витрина.

### Не делаем (осознанно)
- **Своё авто-исполнение на ключах юзеров** — гейт на executor остаётся (нет доказанного
  края); Cornix-совместимость даёт авто-трейдинг чужими руками без нашей ответственности.
- **Поднятие цены до рыночных $99** — до K2 и стабильного трек-рекорда цена «в 5 раз ниже
  рынка» — это аргумент, а не проблема.
- Discord/i18n/платная реклама — по-прежнему за K2 (TOP_LEVEL_PLAN).

## Верификация (как всегда)
Каждый пункт: тесты + ruff/mypy + живой рестарт + живая проверка реальным Telegram API +
коммит через pre-commit hook. Платёжные пути — с фейковыми tg_id на живой БД + FK-aware
cleanup. Ничего в канал без прогона в DM админу.
