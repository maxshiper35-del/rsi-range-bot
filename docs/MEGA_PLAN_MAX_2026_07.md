# МЕГА-ПЛАН MAX: максимальная трансформация бота (2026-07)

Запрос владельца: «максимальное изменение для бота». Этот документ — потолок амбиций при
сохранении двух несущих стен: **честность как продукт** (края у стратегии по бэктесту нет —
продаём инструмент и неподдельную историю) и **гейты роста** (K-вехи из TOP_LEVEL_PLAN:
не жечь деньги/репутацию до подтверждённого трек-рекорда). Cornix пропущен решением
владельца (2026-07-10). Волна 1 прежнего мега-плана исполнена (paid media + /refund);
партнёрка Stars ждёт одного клика владельца в BotFather.

Итог трансформации: **из «бота с постами» → в платформу**: приложение внутри Telegram,
исполняемый (а не расчётный) трек-рекорд, растущая вселенная инструментов, монетизационная
лестница из шести ступеней и публично проверяемое доверие.

---

## ТРИ БОЛЬШИЕ СТАВКИ (само «максимальное изменение»)

### Ставка 1 — Mini App: бот становится приложением
Самый видимый сдвиг для юзера. Telegram Mini App (TWA) как «главный экран» продукта:

- **Дашборд**: живой трек-рекорд (все сделки из `signals.db`), винрейт/экспектация,
  разбивка по сетапам/символам, эквити-кривая; интерактивный график сигнала
  (lightweight-charts — open-source движок TradingView, вместо статичного PNG).
- **Проверяемость в один клик**: страница верификации внутри приложения — скачай CSV,
  сверь sha256 с опубликованным в канале (Myfxbook-паттерн «сверено с биржей»).
- **Оплата не выходя из приложения**: Stars-инвойсы внутри TWA (Bot API 8.0+),
  все тиры лестницы (ниже).
- **Дистрибуция**: main Mini App + приём Stars = заявка в Mini App Store Telegram —
  бесплатный канал установки, которого нет у 99% сигнальных ботов.

Техплан: статический SPA (без бэкенда-сервера!) — бот уже умеет отдавать данные;
добавить лёгкий HTTP-эндпоинт в процесс бота (aiohttp, тот же event loop) отдающий
JSON `/api/stats`, `/api/trades`, `/api/board` + валидацию `initData` (HMAC — гайд
в скилле telegram-dev). Хостинг статики: GitHub Pages/Cloudflare Pages (бесплатно),
API — через Cloudflare Tunnel к локальному Mac (бот и так живёт локально по решению
владельца; туннель = HTTPS без VPS). Объём: самая большая разработка плана (~недели),
делается инкрементально: v1 = read-only дашборд, v2 = оплата, v3 = Store.

### Ставка 2 — Исполняемый трек-рекорд: демо-счёт Bybit (testnet)
Качественный скачок честности, недоступный конкурентам на словах: сигналы не «скорятся
по барам», а **реально исполняются** на официальном testnet Bybit тем же ccxt
(`set_sandbox_mode(True)` — паттерн из скилла ccxt):

- На каждый сигнал — реальный лимитный ордер на testnet; филлы/стопы/тейки приходят
  ОТ БИРЖИ, а не из нашего скоринга.
- В канал — пометка «исполнено на демо-счёте: ордер #…»; расхождения теория/исполнение
  (проскальзывание, частичные филлы) публикуются как есть — это контент про честность.
- Наш bar-скоринг остаётся вторым, независимым контуром — сверка двух источников
  раз в неделю = ещё один слой проверяемости.
- **Гейт на живой executor НЕ трогается**: чужие деньги/ключи — только после
  доказанного края (n≥100+ на сетап, положительная экспектация). Testnet — это
  витрина честности, не торговля.

Техплан: `app/exec/paper_exchange.py` (ccxt bybit + sandbox), таблица `exec_orders`
(migration 010), хук в `_broadcast` (ордер при сигнале) и в poller-такт (sync статусов),
рантайм-флаг `testnet_exec_enabled` (дефолт ВЫКЛ), API-ключи testnet в `.env`
(бесплатные, регистрация walletом владельца — 10 минут). Объём: ~2-3 дня.

### Ставка 3 — Вселенная инструментов: авто-watchlist топ-N
Сейчас 3 захардкоженных символа. Максимальное изменение охвата:

- **Авто-ротация watchlist**: раз в сутки тянуть топ-N (15–25) ликвидных USDT-перпов
  Bybit по объёму (ccxt `fetch_tickers`), фильтры: мин. объём 24ч, возраст листинга,
  спред; руками — только blacklist. Больше инструментов × те же сетапы = быстрее
  копится n для статистической значимости (сейчас главный тормоз K2).
- **Пер-символьный health**: `/bysetup`-стиль разбивка по символам уже есть — добавить
  авто-отключение символа при серии стопов (по образцу consecutive_losses-алерта,
  но с действием за флагом).
- Пре-условие: бэктест-прогон каждого кандидата (CLI уже умеет: `--symbol X --months 6`),
  порог допуска — не хуже нейтрали по экспектации.

Техплан: `runtime.watchlist_auto_enabled` (дефолт ВЫКЛ), `market_data.refresh_watchlist()`
в сутки-такте `_maintenance`, migration не нужна (symbols уже runtime-настройка).
Объём: ~1-2 дня + сутки бэктест-прогонов.

## МОНЕТИЗАЦИОННАЯ ЛЕСТНИЦА (6 ступеней, 4 уже есть)

| Ступень | Цена | Статус |
|---|---|---|
| Триал при /start | 0 (5 дней) | ✅ живёт |
| Разовый сигнал (paid media) | N⭐ (наст. в админке) | ✅ код готов, **включить = 1 клик владельца** |
| Пробный тариф | 10⭐ / 5 часов | ✅ живёт |
| Месяц | 1000⭐ / 30 дней | ✅ живёт |
| **Квартал/Год** | ~2500⭐/90д, ~8000⭐/365д | ➕ разовые инвойсы (нативные Stars-подписки >30д невозможны — проверено в доках), код = копия intro-тарифа, ~час |
| **Lifetime** | ~15000⭐ (бенчмарк $729) | ➕ то же, `paid_until=2099` |

Плюс два внешних рычага (только владелец): **партнёрка Stars** в BotFather (комиссия
10–20% — готовая рефералка, Telegram сам считает и платит) и **VIP-канал** на нативной
Stars-подписке (плат. invite-link, авто-добавление/удаление платформой — DM-рассылка
остаётся параллельным рельсом).

## ДОВЕРИЕ КАК ПРОДУКТ (дёшево, делает бренд)

1. **Лендинг-верификатор** (страница на GitHub Pages): «скачай CSV → проверь sha256 →
   сверь с закрепом канала» + FAQ честности + бейджи вех. Входит в Mini App (Ставка 1),
   но самостоятельная страница — за день.
2. **Вехи как контент**: авто-пост при достижении рубежей (25-я сделка, 100-я, первый
   квартал истории) — генератор уже почти есть (карточка недели), нужен триггер по счётчику.
3. **LLM-дайджест недели** (опционально): человекочитаемый разбор «что происходило с
   сетапами на неделе» поверх фактических цифр журнала — строго описательный, без
   прогнозов (бренд!). Клод-API, ~день. Дешёвый контент-мультипликатор для канала.
4. **Каталоги**: заявки в TGStat/Telemetr + независимые трекеры сигнальных сервисов —
   после K2 (там нужен объём истории).

## ЧТО СОЗНАТЕЛЬНО НЕ ДЕЛАЕМ

- **VPS/облако** — бот живёт на Mac по решению владельца; Cloudflare Tunnel закрывает
  вопрос HTTPS для Mini App без переезда.
- **Cornix** — пропущен решением владельца 2026-07-10 (код блока остаётся за флагом).
- **Свой копитрейдинг/executor** — жёсткий гейт до статистически доказанного края.
- **ML-предикторы/«ИИ-сигналы»** — противоречит бренду честности при текущем n.

## Верификация (стандарт проекта, без изменений)

Каждый пункт: тесты → ruff/mypy → живой рестарт → живая проверка реальным Telegram/биржей
→ коммит через pre-commit hook. Платёжное — с фейковыми tg_id на живой БД. Новые форматы
канала — сначала DM админу. Testnet-исполнение — неделя параллельной работы двух контуров
(биржа vs bar-скоринг) до включения пометок в канале.
